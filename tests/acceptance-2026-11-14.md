# 产品功能与体验验收 · 2026-11-14

本轮不包含首次使用导引、付费、商店或官网分发。正式运行与 UI 验收仅使用 `/Applications/Panelet.app`，通过 `./build.sh --install` 更新，沿用已选定的 Apple Development 签名及 `dev.cmkk.panelet`。没有重置 TCC、强杀 Panelet 或启动构建目录中的 Panelet。

## 本轮功能

- 启动与分屏前检测必要私有接口；诊断页可重新检测。必要接口缺失时阻止新分屏，保留恢复入口；可选接口缺失会提示能力受限。虚拟显示器类使用弱链接。检测不会创建显示器，接口存在不代表运行行为必然兼容。
- 选窗后确认、交换位置、可选自动开始；收藏组合跨重启保存，按应用标识和当前窗口重新匹配，歧义或应用关闭时要求补选。应用退出后清除失效卡片和选择。
- 每块显示器保存方向、1:1 / 2:1 / 1:2 比例、画面模式和名称；提供识别标记和小分区提示。活动分屏期间锁定布局设置。
- 安静启动、用户主动开启的登录启动、中英文界面、帮助/隐私/兼容性说明、关于与反馈入口。
- 明确区分结束组合与合并桌面，新增恢复所有显示器；恢复不完整时保留记录，并说明待恢复的窗口位置/尺寸和状态数量。
- 记录操作耗时、主动取消、失败与恢复结果，以及采集帧、提交帧、合并待显示帧和提交排队时间。诊断报告先预览，再复制或导出；只包含白名单字段，不导出原始日志、窗口标题、应用列表、屏幕名称/序列号或用户路径。界面原始日志限制为最近 500 行。

## 环境与方法

- Apple M4，16 GiB 内存，macOS 27.0.1（26A434）。
- 一块 Mi Monitor：2560×1440 点、5120×2880 像素、2×、60 Hz。
- 屏幕录制与辅助功能经用户明确同意后开启，之后各次更新沿用授权。
- 使用独立的 AppKit QA 应用，通过真实选窗面板和设置完成操作；QA 应用自行记录窗口位置、尺寸、显示器 ID 和全屏事件。没有直接调用产品会话方法代替 UI 操作。
- 快照位于本机 `build/product-acceptance/`；QA 状态写入 `/tmp/panelet-product-acceptance/`，避免外置磁盘访问权限阻塞测试应用。未关闭用户工作应用或文档。

## 短时稳定性与性能

持续全屏运行 300.65 秒，61 次采样；所有采样点两个测试窗口均保持全屏，QA 应用持续响应。期间打开设置和帮助、切换焦点以及测试快捷键冲突，没有意外还原。

- Panelet 进程 CPU 采样均值约 3.6%，峰值 10.1%。
- RSS 最低约 94.7 MiB、最高 123.3 MiB、最后 114.0 MiB；期间创建过帮助和设置界面。
- 一次记录中：独立桌面准备 5.23 秒，已有桌面上的窗口组合准备 2.66 秒，结束组合恢复 1.86 秒。
- 当时两路最长提交排队约 25.7 / 24.4 ms。此值仅测量收到采集帧到提交图层之间的排队，不能作为端到端延迟或显示器刷新率。

这些是本机、本次操作的样本，未包括 WindowServer/GPU 的整体成本，也不构成长期无泄漏或所有场景性能保证。

## 验收发现并修复

1. 启动恢复只查询普通 AX 窗口列表，后台应用可能不返回全部窗口，导致位置已恢复但记录无法清除。现在复用分屏准备的精确窗口查找和限时激活流程，补充失败日志；重新执行完整启动恢复测试通过。
2. 部分界面仍显示系统屏幕名，现已统一使用自定义名。
3. 英文操作按钮过长，已缩短并复查布局。
4. 已退出应用的选窗卡片可能滞留，现监听退出通知并清除选择，异步扫描结果也会排除已经退出的进程。
5. 主动取消不再计入失败次数；诊断预览和帮助保持单实例，避免多个报告窗口复制内容不一致。
6. Edge 在显示器重排后接受位置修改，但可能不接受普通窗口尺寸修改。迁移现在刷新窗口句柄、激活选中窗口；无法缩小时，只有窗口中心和最大覆盖区域都明确属于目标屏，才继续请求原生全屏。最终仍须确认两个窗口都在正确分区全屏，否则回滚。新增了歧义归属、超大窗口及居中归属的几何测试，Edge + TextEdit 与同应用双窗口复测通过。
